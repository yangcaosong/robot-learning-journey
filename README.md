

\# Robot Learning Journey



从 Python 视觉入门到实体机器人的持续学习与实践。



\## 项目目标



逐步掌握机器人视觉、Linux、嵌入式系统、

ROS 2、运动控制、强化学习和四足机器人仿真部署。



\## Hardware



\- Orange Pi 5 Plus

\- RK3588

\- USB Camera（后续接入）

\- Sensors and actuators（逐步接入）



\## Development Environment



\- Windows

\- Python 3.11

\- OpenCV

\- NumPy

\- Ubuntu / Linux on Orange Pi
